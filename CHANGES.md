# Poco AI — обновление v3

Кидать поверх проекта (структура папок сохранена). Затем: `pip install -U -r requirements.txt`.

## Новое
- **Вкладка «🎙 Голос»** (рядом с «Видео» и «Фото»), ElevenLabs больше не в списке видео-моделей.
  * ✍️ Текст → голос: напиши текст сообщением в чат
  * 🎤 Переозвучка: отправь голосовое/аудио — голос заменится на выбранный
  * выбор голоса кнопками (список `VOICES` в config.py)
  * язык озвучки теперь определяется по тексту (раньше всегда стоял "en" — отсюда «странный» русский)
  * `/voice текст` открывает эту вкладку сразу
- **Один короткий /start** для группы и лички (раньше в группе был длинный список моделей).
  Очередь тоже сокращена: «В очереди #N» + одна строка параметров.
- **Видео**: обложка (постер-кадр), 🎉 эффект в личке (если Telegram не примет — отправится как раньше),
  кнопки «Ещё видео / Фото» под результатом.
- Статус генерации: бар ▰▰▱▱ + крутящаяся луна, промпт в сворачиваемой цитате.
- Цветные кнопки (style) везде, три вкладки сверху.
- **aiogram >= 3.31.0** (Bot API 10.3).
- **Вотермарка**: старая анимация, новая надпись (шрифт, декодинг букв, блик, отражение, искры).
- **GitHub**: `ci.yml` (проверка синтаксиса, ошибок и импортов на PR/ветках),
  `bot_24_7.yml` (Python 3.12, кэш pip, FFmpeg, меньше прав у токена).

## Не вошло (специально)
- Motion Control — нужен Payload запроса из DevTools (тело POST /video/process).
- sendMessageDraft: это превью на 30 сек, для рендера на минуты не подходит.
- Rich Message и эфемерные сообщения в группе: не стал включать без проверки на живом боте.
- Виджеты — как договаривались, без них.
