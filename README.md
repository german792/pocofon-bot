# POCO AI — Telegram Бот для генерации видео (Seedance 2.5)

Telegram-бот на базе нейросети **Seedance 2.5**, работающий через прямое взаимодействие с API сайта без ограничений и платных ключей.

## 🚀 Возможности
- **Два режима создания видео:**
  - **Image-to-Video:** Отправка фото + текстовое описание (персонаж, действие, окружение).
  - **Text-to-Video:** Генерация видео только по тексту (автоматическое создание опорного кадра).
- **Интерактивные инлайн-кнопки в Telegram:**
  - Выбор длительности: `5 сек`, `10 сек`, `15 сек` или `⚡ Авто`.
  - Выбор разрешения: `480p`, `720p HD`, `1080p FHD`.
  - Выбор формата (соотношения сторон): `16:9 🖥`, `9:16 📱`, `1:1 ⏹`.
  - Переключатель звука: `🔊 Звук: Вкл/Выкл`.
- **Очередь задач (FIFO):**
  - Задачи выполняются строго последовательно по 1 видео за раз, чтобы не перегружать сервер и избегать блокировок.
  - Пользователь в реальном времени видит свою позицию в очереди и статус генерации.
- **Авторизация:**
  - Бот автоматически входит в систему и продлевает сессию (кука `sid`).

## 🛠 Запуск бота

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск:
```bash
python bot.py
```

---

## ⚙️ Конфигурация (.env)
Скопируйте пример конфигурации и укажите свои данные:
```bash
cp .env.example .env
```

Параметры в `.env`:
```ini
BOT_TOKEN=ваш_токен_бота
DAVINCI_TOKEN=ваш_токен
DAVINCI_REFRESH_TOKEN=ваш_refresh_токен
```

---

## 🔐 Секреты

Токены и пароли больше не хранятся в коде. Локально задайте их в `.env`, а для GitHub Actions — в **Settings → Secrets and variables → Actions**:

`BOT_TOKEN`, `DAVINCI_TOKEN`, `DAVINCI_REFRESH_TOKEN`, `ADMIN_PASSWORD`, `API_PASSWORD`, при желании `KEY_SIGNING_SECRET`.

Если `KEY_SIGNING_SECRET` не задан, ключи подписываются `ADMIN_PASSWORD` — тогда старые ключи `POCO-…` продолжают работать, пока пароль тот же.
